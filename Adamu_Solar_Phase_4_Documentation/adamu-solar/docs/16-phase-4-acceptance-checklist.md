# Adamu Solar --- Phase 4 Acceptance Checklist

**Document ID:** AS-P4-AC-001\
**Version:** 1.0\
**Status:** Ready for implementation review

## Shared layout

-   [ ] Header matches approved brand colors and typography.
-   [ ] Logo/wordmark is visible and returns to the homepage.
-   [ ] Desktop navigation links are meaningful.
-   [ ] Mobile menu works with keyboard and touch.
-   [ ] EN \| አማ control behaves as specified.
-   [ ] Footer includes approved navigation and verified contact details
    only.
-   [ ] Focus indicators are visible and controls have accessible names.

## Homepage

-   [ ] Hero contains approved tagline and concise supporting text.
-   [ ] Hero CTA has a working destination/action.
-   [ ] Services overview covers all five agreed service categories.
-   [ ] Featured project content uses approved photos or a clear
    placeholder state.
-   [ ] About preview uses only verified professional facts.
-   [ ] Contact CTA is clear and usable on mobile.
-   [ ] No fabricated testimonials, certificates, metrics, warranties,
    prices, or project claims.

## Responsive behavior

-   [ ] No horizontal overflow at 320--375 px.
-   [ ] Layout tested around 390--430 px, 768 px, 1280 px, and 1440 px.
-   [ ] Buttons and links are comfortably tappable.
-   [ ] Text wraps correctly in English and Amharic.
-   [ ] Images do not distort and important content is not cropped.
-   [ ] Header and mobile menu do not obscure page content.

## Quality

-   [ ] Actual lint script passes.
-   [ ] Production build passes.
-   [ ] No broken images or dead links.
-   [ ] No unexpected browser console errors.
-   [ ] Images have suitable alt text.
-   [ ] No secrets or private customer data are committed.
-   [ ] Git diff reviewed and intended changes committed.
-   [ ] Adamu reviews and approves the homepage.

## Phase exit

Do not mark Phase 4 complete until the checklist has been tested against
the running site and the client has approved the result.
