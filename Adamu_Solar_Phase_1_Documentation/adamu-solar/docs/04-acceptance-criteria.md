# Adamu Solar Website --- Acceptance Criteria

**Document ID:** AS-AC-001\
**Version:** 1.0\
**Status:** Draft for client validation

A requirement is accepted only when the relevant checks pass and Adamu
approves the public-facing content.

## 1. Pages and content

-   [ ] **AC-01:** Home, About, Services, Projects, and Contact pages
    load successfully.
-   [ ] **AC-02:** Each page has a clear heading and page-specific
    content.
-   [ ] **AC-03:** The site identifies Adamu Solar and Adamu Shewa
    consistently.
-   [ ] **AC-04:** Service descriptions and service locations match
    client-approved information.
-   [ ] **AC-05:** No placeholder copy, fake testimonials, invented
    credentials, or unsupported claims remain.
-   [ ] **AC-06:** Every published project image and testimonial has
    been approved for use.

## 2. English and Amharic

-   [ ] **AC-07:** Visitors can switch between English and Amharic.
-   [ ] **AC-08:** All five pages have reviewed content in both
    languages.
-   [ ] **AC-09:** Navigation, buttons, form labels, validation
    messages, and footer are translated.
-   [ ] **AC-10:** Amharic characters render correctly without clipping
    or broken layout on mobile and desktop.
-   [ ] **AC-11:** Language switching preserves the equivalent page
    where possible.

## 3. Contact journeys

-   [ ] **AC-12:** The phone link opens the calling interface on a
    compatible device and uses the approved number.
-   [ ] **AC-13:** The WhatsApp link opens the intended conversation
    with the approved WhatsApp number.
-   [ ] **AC-14:** The inquiry form clearly labels required fields and
    validates missing or invalid input.
-   [ ] **AC-15:** A valid form submission reaches the agreed
    destination.
-   [ ] **AC-16:** Successful submission produces a clear confirmation
    message.
-   [ ] **AC-17:** A failed submission produces a useful error message
    and does not falsely claim success.
-   [ ] **AC-18:** The privacy notice explains the intended use of
    submitted inquiry information.
-   [ ] **AC-19:** Facebook and Telegram links open the correct
    client-approved profiles.

## 4. Responsive design and usability

-   [ ] **AC-20:** Pages are usable at common mobile, tablet, and
    desktop viewport sizes.
-   [ ] **AC-21:** No unintended horizontal scrolling occurs at
    supported viewport sizes.
-   [ ] **AC-22:** Navigation, language selection, form fields, and
    contact actions are usable by touch.
-   [ ] **AC-23:** Text is readable, controls have visible focus states,
    and color contrast is checked.
-   [ ] **AC-24:** Images have appropriate alt text when informative;
    decorative images are handled appropriately.

## 5. Technical quality and SEO

-   [ ] **AC-25:** Production build completes without errors.
-   [ ] **AC-26:** Internal navigation and all external links are
    checked.
-   [ ] **AC-27:** Each page has a relevant title and meta description.
-   [ ] **AC-28:** Page language metadata is correct for the selected
    language.
-   [ ] **AC-29:** Images are appropriately sized and optimized.
-   [ ] **AC-30:** HTTPS is enabled on the production deployment.
-   [ ] **AC-31:** No secrets, tokens, or private API keys are committed
    to the repository.
-   [ ] **AC-32:** Sitemap and robots configuration are appropriate for
    the production site.
-   [ ] **AC-33:** No known critical or high-impact defects remain
    unresolved at launch.

## 6. Deployment and handover

-   [ ] **AC-34:** The production URL loads from a separate device or
    browser session.
-   [ ] **AC-35:** The production phone, WhatsApp, social, and form
    journeys are tested---not just the local version.
-   [ ] **AC-36:** The Git repository contains the approved source code
    and a useful README.
-   [ ] **AC-37:** Handover notes explain how to update text, photos,
    contact details, and translations.
-   [ ] **AC-38:** Domain ownership, hosting account ownership, form
    delivery, and any recurring costs are agreed with Adamu.
-   [ ] **AC-39:** Adamu reviews the live website and approves launch.

## 7. Launch decision

The website is ready to launch when: 1. All mandatory acceptance checks
pass. 2. The inquiry form is connected to a real, tested destination. 3.
Client content and publication permissions are approved. 4. No critical
defects remain. 5. Adamu approves the production version.

If a criterion cannot be met, record it as a known issue, explain its
impact, and agree whether launch must be delayed or the item can be
deferred.
